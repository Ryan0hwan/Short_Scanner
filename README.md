# 숏 후보 스캐너

S&P 500과 내 관심종목(약 680종목)에서 **20일선·50일선을 이탈했다가 아래에서 다시 올라와 그 선에 막히고 밀린 종목**을 찾아, 손절가·목표가·손익비와 함께 디스코드로 보냅니다. 매일 미국 장 마감 후 1회 실행됩니다.

## 알림 조건 (모두 충족해야 알림)

20일선과 50일선을 각각 따로 확인합니다.

| 구분 | 조건 |
|---|---|
| ① 이탈 | 3~20거래일 전에 종가가 선 아래로 내려갔고, 그 전 10거래일은 계속 선 위에 있었음 (원래 지지선). 이탈 후 오늘까지 계속 선 아래 |
| ② 되돌림 | 어제 종가는 선 아래, 오늘 고가가 선의 ±0.5% 안까지 올라옴 |
| ③ 저항 확인 | 오늘 종가가 선 아래, 당일 범위의 하단 절반에서 마감 (윗꼬리) |
| ④ 이평선 하락 | 그 선이 5거래일 전보다 낮음 |
| ⑤ 이탈일 거래량 | 50일 평균의 1.5배 이상 |
| ⑥ 약한 반등 | 이탈 다음 날부터 오늘까지 평균 거래량 < 이탈일 거래량 |
| ⑦ 약한 종목 | RS 50 미만 **또는** 3개월 수익률이 SPY보다 낮음 |
| 기본 필터 | 주가 $10 이상, 50일 평균 거래대금 $2,000만 이상 |

**⑧ 시장 환경**은 조건이 아니라 표시만 합니다. 알림 맨 위에 QQQ와 SPY가 50일선 위인지 아래인지 나옵니다. 지수가 50일선 아래일 때 숏 성공률이 높습니다.

## 디스코드 표 보는 법

| 열 | 의미 |
|---|---|
| RS | 상대강도(1~99). 낮을수록 시장보다 약함 |
| LDR | `Y`면 최근 60거래일 안에 추세 템플릿(가격 조건 1~7)을 만족했던 **전 주도주**. 추세 전환 초입이라 하락 폭이 큰 편 |
| BRK | 이탈한 지 며칠 됐는지(거래일) |
| VOLx | 이탈일 거래량 ÷ 50일 평균 |
| BNC | 되돌림 구간 평균 거래량 ÷ 이탈일 거래량. 낮을수록 반등이 약함 |
| MA | 오늘 저항선(20일선 또는 50일선) 값 |
| LAST | 종가 (진입 기준가) |
| STOP | 손절가 = 오늘 고가. 이 위로 올라가면 저항 실패 |
| TGT | 1차 목표가 = 이탈 후 어제까지의 최저가. 이미 그 아래면 `-` |
| R:R | 손익비 = (종가 − 목표가) ÷ (손절가 − 종가). 이 순서로 정렬 |

## 실행 시각

평일 한국 시각 **07:00** (미국 장 마감 후 확정 일봉 기준). GitHub 특성상 5~30분 늦을 수 있습니다.

## 설치 (새 저장소, 약 10분)

### 1. 디스코드 채널·웹후크
1. 채널 목록 **채팅 채널** 옆 **+** → 새 채널 생성 (예: `숏후보`)
2. 새 채널 옆 **⚙** → **연동** → **웹후크** → **새 웹후크**
3. 생긴 봇을 펼쳐 **채널**이 새 채널인지 확인 → **웹후크 URL 복사**

### 2. GitHub 저장소
1. 오른쪽 위 **+** → **New repository** → 이름 입력 (예: `short-scanner`) → **Public** → **Create repository**
2. **uploading an existing file** → `short.py`, `watchlist.txt`, `requirements.txt`, `README.md` 끌어다 놓기 → **Commit changes**
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` 입력 → zip 안의 `main.yml` 내용 붙여넣기 → **Commit changes**

### 3. 웹후크 주소 등록
1. **Settings** → 왼쪽 **Secrets and variables** → **Actions**
2. **New repository secret** → Name: `DISCORD_WEBHOOK_URL` / Secret: 1-3에서 복사한 주소 → **Add secret**

### 4. 테스트
1. **Actions** 탭 → 왼쪽 **Short Setup Scanner** → **Run workflow** → **Run workflow**
2. 몇 분 뒤 새 채널에 시장 상태 요약, 20일선 저항 표, 50일선 저항 표가 오면 끝

## 설정 바꾸기 (`short.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MAS` | 20,50 | 저항선으로 볼 SMA |
| `BRK_MIN` / `BRK_MAX` | 3 / 20 | ① 이탈 후 경과일 범위 |
| `ABOVE_BEFORE` | 10 | ① 이탈 전 선 위에 있었어야 하는 기간 |
| `TOUCH_TOL_PCT` | 0.5 | ② 고가가 선에 닿은 것으로 보는 오차(%) |
| `CLOSE_POS_MAX` | 0.5 | ③ 종가 위치 (0 = 저가, 1 = 고가) |
| `SLOPE_DAYS` | 5 | ④ 이평선 하락 비교 기간 |
| `BRK_VOL_X` | 1.5 | ⑤ 이탈일 거래량 배수 |
| `RS_MAX` | 50 | ⑦ RS 상한 |
| `REQUIRE_SLOPE` / `REQUIRE_BRK_VOL` / `REQUIRE_WEAK_BOUNCE` / `REQUIRE_WEAK_RS` | 1 | ④~⑦ 조건 켜기(1)/끄기(0) |
| `MIN_PRICE` / `MIN_DOLLAR_VOL` | 10 / 20000000 | 기본 필터 |

## 알아둘 점

- **실적 발표 일정과 공매도 잔고는 확인하지 않습니다.** 무료 데이터로는 정확히 받기 어렵습니다. 실적 직전 종목이나 공매도 잔고가 높은 종목은 급등 위험이 크니 진입 전에 직접 확인하세요.
- 국내 증권사 일반 계좌로는 미국 주식 직접 공매도가 어려워서, 보통 풋옵션이나 인버스 ETF를 씁니다. 기본 필터의 거래대금 $2,000만은 옵션 거래가 어느 정도 되는 종목을 남기기 위한 기준입니다.
- 시세는 야후 파이낸스 무료 데이터이고, 야후에 없는 티커는 빠집니다.
